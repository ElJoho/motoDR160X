# motoDR160X

3D-printed and custom parts for a DR160X motorcycle, designed in FreeCAD.

## Contents

- `espejoRetrovisor/` – rear-view mirror parts (M10x5mm washer, layout part)
- `parrila/` – luggage rack to plate adapter (full and simplified versions), drawings, reference scans and a sketch export macro

Each part includes the FreeCAD source (`.FCStd`) and an STL export for printing.

## Cloning

Large files (CAD, STL, images, PDFs) are stored with [Git LFS](https://git-lfs.com/). Install it before cloning:

```bash
git lfs install
git clone <repo-url>
```
